# Домашнее задание к занятию «Компоненты Kubernetes»

### Цель задания

Рассчитать требования к кластеру под проект

------

### Задание. Необходимо определить требуемые ресурсы
Известно, что проекту нужны база данных, система кеширования, а само приложение состоит из бекенда и фронтенда. Опишите, какие ресурсы нужны, если известно:

1. Необходимо упаковать приложение в чарт для деплоя в разные окружения. 
2. База данных должна быть отказоустойчивой. Потребляет 4 ГБ ОЗУ в работе, 1 ядро. 3 копии. 
3. Кеш должен быть отказоустойчивый. Потребляет 4 ГБ ОЗУ в работе, 1 ядро. 3 копии. 
4. Фронтенд обрабатывает внешние запросы быстро, отдавая статику. Потребляет не более 50 МБ ОЗУ на каждый экземпляр, 0.2 ядра. 5 копий. 
5. Бекенд потребляет 600 МБ ОЗУ и по 1 ядру на копию. 10 копий.

Ответ:

1. Для работы с чартом нужна утилита helm. Для деплоя в разные окружения нужно создать необходимое количество пространств имен в кластере.
2. Для 3-х копий БД понадобится суммарно 12ГБ ОЗУ и 3 ядра ЦП.
3. Кешу понадобится 12ГБ ОЗУ и 3 ядра ЦП.
4. Для фронтенда нужно около 250МБ ОЗУ и 1 ядро ЦП.
5. Бекенд займет примерно 6ГБ ОЗУ суммарно и 10 ядер ЦП суммарно.

Итого: нужно 30,25 ГБ ОЗУ и 17 ядер ЦП для развертывания приложения только в одно окружение. Для нескольких окружений нужно полученные значения
умножить на количество окружений.

Минимально для работы БД и кеша нужно 3 ноды, по одной копии на ноду. Но с учетом запаса и того факта, что нод должно быть нечетное количество, 
увеличиваем число нод до 5-ти.

Для развертывания приложения только в одно окружение нужно 5 нод, но чтобы в каждую ноду могло поместиться:
- 1 копия БД
- 1 копия кеша
- 2 копии фронтенда
- 3 копии бекенда

Итого на одной ноде для приложения должно быть 4+4+0,05*2+0,6*3 = 9,9 ГБ ОЗУ, округляем до 10-ти ГБ; и 1+1+0,2*2+3 = 5,4 ядра ЦП, округляем до 6-ти ядер.

Добавим 1 ГБ ОЗУ и 1 ядро для операционной системы и служебных ресурсов.

Всего получается 11 ГБ ОЗУ и 7 ядер ЦП для каждой ноды из пяти, в которой будет развернуто одно окружение.
