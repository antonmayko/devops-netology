# Домашнее задание к занятию «Управление доступом»### Цель заданияВ тестовой среде Kubernetes нужно предоставить ограниченный доступ пользователю.------### Задание 1. Создайте конфигурацию для подключения пользователя1. Создайте и подпишите SSL-сертификат для подключения к кластеру.2. Настройте конфигурационный файл kubectl для подключения.3. Создайте роли и все необходимые настройки для пользователя.4. Предусмотрите права пользователя. Пользователь может просматривать логи подов и их конфигурацию (`kubectl logs pod <pod_id>`, `kubectl describe pod <pod_id>`).5. Предоставьте манифесты и скриншоты и/или вывод необходимых команд.Ответ:- манифест role[role.yaml](https://github.com/antonmayko/devops-netology/blob/kuber-09/kuber/kuber-09/role.yaml)- манифест role binding[role-binding.yaml](https://github.com/antonmayko/devops-netology/blob/kuber-09/kuber/kuber-09/role-binding.yaml)Создаем ключ:`openssl genrsa -out test.key 2048`Создаем запрос подписи:`openssl req -new -key test.key -out test.csr -subj "/CN=test/O=ops"`Подписываем сертификат:`openssl x509 -req -in test.csr -CA /var/snap/microk8s/current/certs/ca.crt -CAkey /var/snap/microk8s/current/certs/ca.key -CAcreateserial -out test.crt -days 500`Добавляем в конфигурационный файл нашего пользователя test:`microk8s kubectl config set-credentials test --client-certificate=test.crt --client-key=test.key --embed-certs=true`Теперь конфигурационный файл имеет вид:![kuber](https://github.com/antonmayko/devops-netology/blob/kuber-09/kuber/kuber-09/assets/config.png)После применения роли, роли-биндинга и переключения на тестовый контекст получаем результат:- пользователь `test` может просматривать логи подов:![kuber](https://github.com/antonmayko/devops-netology/blob/kuber-09/kuber/kuber-09/assets/pod-logs.png)Здесь показан вывод консоли тестового пода, который записывается в лог.- пользователь `test` может просматривать конфигурацию подов:![kuber](https://github.com/antonmayko/devops-netology/blob/kuber-09/kuber/kuber-09/assets/pod-describe.png)- пользователь `test` НЕ может просматривать список подов, список пространств имён, список развертываний и т.д.:![kuber](https://github.com/antonmayko/devops-netology/blob/kuber-09/kuber/kuber-09/assets/restrict.png)------
